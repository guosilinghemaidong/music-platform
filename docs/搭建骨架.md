# Day 1 代码逐行分析

## 文件 1：app/config.py
数据库连接地址
格式：mysql+aiomysql://用户名:密码@主机:端口/数据库名?字符集
DATABASE_URL = "mysql+aiomysql://root:ztsmysql@localhost:3306/music_platform?charset=utf8mb4"
JWT 配置
SECRET_KEY = "your-secret-key-change-later" ALGORITHM = "HS256"
### 逐段拆解

| 部分 | 含义 |
|------|------|
| `mysql+aiomysql` | 数据库类型 + 驱动。`mysql` 表示用 MySQL，`aiomysql` 表示用异步驱动 |
| `root` | MySQL 用户名 |
| `ztsmysql` | MySQL 密码 |
| `localhost:3306` | 数据库在本机，端口 3306（MySQL 默认端口） |
| `music_platform` | 数据库名 |
| `charset=utf8mb4` | 字符集，支持中文和 emoji |

> 💡 **固定格式：** `数据库类型+驱动://用户名:密码@主机:端口/数据库名?参数`

| 变量 | 含义 | 什么时候用 |
|------|------|-----------|
| `SECRET_KEY` | JWT 加密用的密钥 | Day 4 生成 Token 时用 |
| `ALGORITHM` | 加密算法，固定 HS256 | Day 4 生成和解析 Token 时用 |

> 💡 JWT 标准算法就是 HS256，密钥用来签名，别人没有密钥就伪造不了 Token。

## 文件 2：app/database.py
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession from app.config import DATABASE_URL
创建异步数据库引擎
engine = create_async_engine( DATABASE_URL, echo=True, pool_size=10, max_overflow=20, )
创建异步会话工厂
AsyncSessionLocal = async_sessionmaker( bind=engine, class_=AsyncSession, expire_on_commit=False )
### 导入解释

| 导入 | 是什么 | 作用 |
|------|--------|------|
| `create_async_engine` | 函数 | 用来创建数据库引擎 |
| `async_sessionmaker` | 函数 | 用来创建会话工厂 |
| `AsyncSession` | 类 | 异步会话，用来执行数据库操作（增删改查） |

> 💡 **固定导入：** 只要用 SQLAlchemy 异步模式，这三个必须导入。

### create_async_engine 参数解释

| 参数 | 含义 | 为什么设这个值 |
|------|------|--------------|
| `DATABASE_URL` | 数据库地址 | 告诉引擎连哪个数据库 |
| `echo=True` | 打印 SQL 日志 | 开发阶段方便调试，上线改成 False |
| `pool_size=10` | 连接池保持 10 个连接 | 提前建好连接，用的时候直接拿 |
| `max_overflow=20` | 最多额外创建 20 个 | 高峰期 10 个不够时，最多加到 30 个 |

> 💡 **连接池理解：** 就像银行开窗口。`pool_size=10` = 平时开 10 个窗口。`max_overflow=20` = 人多时最多加开 20 个窗口。

### async_sessionmaker 参数解释

| 参数 | 含义 | 为什么设这个值 |
|------|------|--------------|
| `bind=engine` | 绑定引擎 | 告诉会话工厂用哪个引擎连数据库 |
| `class_=AsyncSession` | 会话类型 | 指定生成异步会话（支持 async/await） |
| `expire_on_commit=False` | 提交后不过期 | 默认 commit 后数据会"过期"，设 False 后可以直接访问 |

> 💡 **比喻理解：**
> - `engine` = 修好的路（到数据库的通道）
> - `AsyncSessionLocal` = 造车的工厂（每次需要操作数据库时造一辆"车"）
> - 每次接口被调用 → 从工厂拿一辆车（session）→ 跑在路上（engine）→ 执行操作

## 文件 3：app/main.py
from fastapi import FastAPI from app.routers import user
app = FastAPI(title="音乐社交平台", description="FastAPI + Vue3 全栈项目")
app.include_router(user.router)
@app.get("/") async def root(): return {"message": "音乐社交平台 API 运行中！"}
@app.get("/health") async def health_check(): return {"status": "ok"}
### 逐行解释

| 代码 | 含义 |
|------|------|
| `from fastapi import FastAPI` | 导入 FastAPI 类（固定导入） |
| `from app.routers import user` | 导入用户路由模块（Day 3 加的） |
| `app = FastAPI(title=..., description=...)` | 创建 FastAPI 应用实例 |
| `app.include_router(user.router)` | 把 user 模块的所有接口注册到应用 |
| `@app.get("/")` | 注册 GET 路由，路径是 `/`（根路径） |
| `async def root():` | 异步函数，处理请求 |
| `return {...}` | 返回 JSON 数据（FastAPI 自动转字典为 JSON） |

> 💡 **include_router 的好处：** 以后加新模块只需要 `app.include_router(music.router)`，main.py 保持简洁。

## Day 1 总结

| 文件 | 做了什么 | 核心理解 |
|------|---------|---------|
| `config.py` | 存放配置（数据库地址、密钥） | 配置和代码分离，方便修改 |
| `database.py` | 创建数据库引擎和会话工厂 | engine = 连接通道，session = 操作工具 |
| `main.py` | 创建应用 + 注册路由 + 测试接口 | FastAPI 入口，所有功能从这里启动 |

**Day 1 的本质：** 搭好骨架，让项目能启动、能连数据库、能返回数据。
