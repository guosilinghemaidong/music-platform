1. 为什么需要 CORS？
    前端：http://localhost:5173
    后端：http://localhost:8000
    端口不同，浏览器出于安全考虑会拦截请求。CORS 就是告诉后端："允许这个前端来访问我"。

# 后端 main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # 允许谁访问
    allow_methods=["*"],    # 允许什么方法（GET/POST/PUT/DELETE）
    allow_headers=["*"],    # 允许什么请求头
)
💡 本质： 后端在响应头里加了 Access-Control-Allow-Origin: http://localhost:5173，浏览器看到这个头就不拦截了。

2. Axios 是什么？
    Axios 是前端发 HTTP 请求的工具，就像后端的 db.execute() 操作数据库一样，axios 用来调用后端接口。

// frontend/src/api/index.js
import axios from 'axios'

const api = axios.create({
  baseURL: 'http://localhost:8000'  // 后端地址
})
💡 本质： 封装了一个请求工具，以后每次调接口不用写完整的 URL，直接 api.post('/user/register') 就行。
